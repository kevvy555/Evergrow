# Evergrow Roadmap

## Phase 0 — Core feel

- [x] Tap to create
- [x] 3-object spatial merges
- [x] Recursive chain reactions
- [x] Seven visible progression levels
- [x] Touch-friendly responsive 9×18 board
- [x] Score, population, stage and version HUD
- [x] Local autosave/reset
- [x] Richer particles, lightweight audio and haptics
- [x] Merge-ready pair highlighting

## Phase 0.5 — Delight loop (v0.2.0)

- [x] Flow streak for consecutive merge-producing taps
- [x] Flow bonus scoring
- [x] Life Sparks: periodic glowing bonus targets requiring no new controls
- [x] One-at-a-time short objectives with automatic rewards
- [x] Large first-discovery celebrations and discovery bonuses
- [x] Feedback mute toggle
- [x] Persist new reward/progression state with backward-compatible save loading

## Phase 1 — Living world (next)

- Weather and day/night cycle
- Forest spread and water influence
- Simple inhabitants and traffic
- Positive/negative world conditions
- Discoveries that emerge from combinations

## Phase 2 — Meaningful choice

- Occasional two-choice evolution decisions
- Multiple valid development paths
- Soft ecological/economic trade-offs
- Short goals that never block sandbox play

## Phase 3 — Retention without chores

- Daily shared challenge world
- Discovery journal
- Rare world traits
- Gentle offline progression
- One-tap friend gifts

## Phase 4 — Scale reveal

- Planet completion and camera pull-back
- Multiple autonomous planets
- Solar-system layer
- Preserve the same tap-first interaction language

## Design rules

1. A new player must understand the primary action without a tutorial.
2. New systems may deepen consequences, but must not multiply controls.
3. Failure creates a problem to solve rather than destroying progress.
4. The player should see a satisfying response within 250 ms of every tap.
5. Complexity belongs in simulation and emergence, not menus.
6. Reward systems should make good play feel better, not make ordinary play feel bad.
7. Never add a system merely because other free-to-play games have it.
